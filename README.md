# Bruna Assis — Mídia Kit

Site de apresentação profissional (mídia kit) da criadora de conteúdo Bruna Assis, [@bruassiss](https://instagram.com/bruassiss).

Site publicado: https://bassisoliv.github.io/portfolio/

## Sobre

Mídia kit com números do perfil, pilares de conteúdo, portfólio de trabalhos com marcas, cases de sucesso e formas de contato para parcerias.

## Estrutura

- index.html — página única do site
- assets/bruna.jpg — foto de perfil usada na seção "Sobre"

## Como atualizar

1. Edite o index.html diretamente (número de seguidores, marcas, links de vídeos etc.)
2. Para trocar a foto, substitua o arquivo assets/bruna.jpg mantendo o mesmo nome
3. Faça commit das alterações — o GitHub Pages atualiza o site publicado automaticamente em 1 a 3 minutos
